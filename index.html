Efficiency factor

Metres covered per heartbeat in the running intervals (speed ÷ heart rate). If the number goes up, I'm getting fitter, whatever the pace.

Heart rate drift

Peak heart rate in the last three intervals minus the first three. Close to zero means the body handles the load.

Running dynamics

Measured by the heart rate strap, as averages for the running intervals. Running slower gives longer ground contact and a higher ratio, so these numbers should be read together with the pace.

Ground contact time

Milliseconds per step. Lower is usually more efficient.

Vertical oscillation

How much I bounce up and down, in cm.

Vertical ratio

Bounce divided by stride length. Lower means less energy goes upwards.

Strength and injury prevention

Going from zero to running puts a lot of new load on muscles, tendons and joints. Strength and mobility sessions for hips, glutes and core help the body handle it, so I can keep running week after week instead of ending up on the sidelines.

Privacy and cookies

In short

This site uses no cookies, no tracking and no analytics tools, so there is nothing you need to consent to.

Hosting

The site is hosted on GitHub Pages, a service from GitHub, Inc. (part of Microsoft) in the USA. When you visit, GitHub receives your IP address and standard technical information such as browser type and time, and may keep it in logs to run and secure the service. I don't have access to these logs, and I don't collect any information about you myself.

Because GitHub is based in the USA, this information may be transferred outside the EU/EEA. GitHub states that such transfers are covered by the EU–US Data Privacy Framework and the EU's standard contractual clauses. Read more in the GitHub Privacy Statement.

Language choice

If you switch language, your choice is saved in your own browser so the site remembers it next time. It is never sent anywhere.

YouTube

YouTube videos only load when you tap them. Until then, nothing is sent to YouTube. Links to the channel open YouTube in a new tab, where YouTube's own terms apply.

Fonts

The fonts are stored on this site itself, so no third party is contacted when the page loads.

Training data

The numbers on this site are my own. No maps, GPS tracks, locations or dates are shown, and elevation is only shown as relative.

Contact

Questions can be sent via the YouTube channel @Lazybonesto5k.
